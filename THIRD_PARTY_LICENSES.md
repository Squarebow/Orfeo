## Native audio engine (Windows)

Orfeo's *Native (beta)* sound engine (`native/`) plays sound sets with
FluidSynth and sends the result straight to the sound card.

Only the Windows downloads include this engine. Mac and Linux downloads don't.

**FluidSynth and the libraries it needs** are shipped **unmodified, as separate
DLLs** in `resources/native/fluidsynth/`, loaded at runtime, from FluidSynth's
official 2.5.7 Windows build (`fluidsynth-v2.5.7-win10-x64-glib.zip`). Under the
LGPL you may replace any of them with your own build of the same library: Orfeo
loads whatever is in that folder and doesn't check the files. The Microsoft Store
copy's folder is read-only, so use a GitHub download for this.

Copies of the exact source code of everything in this section, and of the LAME
encoder above, are kept at https://github.com/Squarebow/Orfeo-third-party-sources.
